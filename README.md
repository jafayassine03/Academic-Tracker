🎓 Student Evaluation System (CLI)

A simple terminal-based Student Evaluation System built using Python and JSON.
This project allows you to manage students and their academic information through a clean command-line interface.
All data is stored locally in a JSON file, making the application lightweight, beginner-friendly, and easy to expand.

📌 Project Objectives

Practice core Python concepts: Work with core Python features such as file handling, loops, conditionals, and exception handling.

Learn how to work with JSON: Use JSON for data persistence and storage, making it easier to manage student information.

Build a structured CLI application: Create a command-line interface for seamless student management.

Create a scalable project: Design the system so it can grow and evolve, with future improvements and features.

Strengthen problem-solving skills: Develop your ability to solve real-world problems by managing and processing data.

⚙️ Current Features

📋 Interactive Terminal Menu: Navigate easily through options.

➕ Add New Students: Store name, age, grade, major, and notes.

👀 View All Students: Display all saved student records.

✏ Edit Student Information: Update age, grade, major, or notes.

🔍 Search Student by Name: Quickly find a student’s details.

🗑 Delete Student: Remove a student from the records.

📊 Sort Students by Grade: Rank students by academic performance.

📈 Calculate Average Grade: Compute the average grade across all students.

🏆 Top Student Report: Identify and display the student with the highest grade.

💾 Automatic JSON File Creation: Creates academictracker.json if it doesn’t exist.

🔐 Safe Exit System: Ensures changes are saved before exiting.

🗂 Local Data Storage: All data stored in academictracker.json.
🛠 Technologies Used

Python 3: The main language for this project.

JSON: Used for file-based storage of student data.

OS module: Handles file management (checking if the file exists, reading, writing).

Built-in Python Libraries: Leveraged to create a user-friendly, interactive CLI experience.

▶ How to Run

Clone or download the repository to your local machine.

Open your terminal and navigate to the project folder.

Run the following command:

python main.py

Make sure you have Python 3 installed on your system.
